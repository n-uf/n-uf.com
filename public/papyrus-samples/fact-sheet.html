1.What it is

A documents engine for documents rendered as HTML and exported as PDF. It is framework-free, so it also runs without a bundler, and it contains no brand, copy or document content of its own.

2.Two packages, one version

PackageWhat it isShips
@n-uf/papyrusThe engine: page contract, sheets, document registry and PDF exporter.Plain ESM JavaScript with type declarations
@n-uf/papyrus-reactReact components built on the engine: page and content blocks, a React-typed registry and print styles.TypeScript source

The two packages always share one version number.

3.One element, one sheet, one page

The class pdf-page marks a page: one element, one sheet on screen, one page in the PDF. sheetCss() gives it its size, A4 (210 × 297 mm) or Letter (8.5 × 11 in), and the exporter counts these elements to check the PDF.

import { SHEETS, sheetCss } from "@n-uf/papyrus";

const css = sheetCss(SHEETS.LETTER);  // US Letter sheets

4.The PDF check

Every PDF is checked before it is written: the page elements, the PDF's page count and the expected pageCount must agree, so a broken render is never saved. This sample was printed with:

papyrus pdf --config papyrus.config.json
