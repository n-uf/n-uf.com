Release notes

26.11.0 to 26.11.2

Same code throughout. All three releases ship the same code as 0.4.1; what changed is the versioning, the licence and where the package is released from. Pin an exact version and read the changelog before you upgrade.

26.11.2

  • The package's homepage is now its overview page, n-uf.com/papyrus. Same code as 26.11.1.

26.11.1

  • Now released from its own repo, n-uf/papyrus, to npmjs (with provenance) as well as GitHub Packages. Same code as 26.11.0; the package now ships this CHANGELOG.

26.11.0

  • Calendar versions (YY.M.R) from now on, like hypr-tiling, doodl and debugsy; @n-uf/papyrus-react shares the version. Same code as 0.4.1: ^0.4.x ranges do not pick this up, so move them to ^26.11.0.
  • License: PolyForm Perimeter 1.0.1 (was UNLICENSED); see LICENSE.
